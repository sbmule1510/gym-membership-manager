# FitZone Gym Membership Manager

A simple Gym Membership Management System developed using Laravel and MySQL.

## Features

- Admin Login
- Dashboard
- Member Management
- Add Member
- Edit Member
- Delete Member
- Membership Plan Management
- Membership Status
- Active Members
- Expiring Members
- Expired Members

## Technologies Used

- Laravel
- PHP
- MySQL
- Blade
- HTML
- CSS

## Database

MySQL database is used to store members, plans and admin information.

## Project Purpose

This project is developed as an academic MCA project to demonstrate CRUD operations and Laravel framework concepts.
